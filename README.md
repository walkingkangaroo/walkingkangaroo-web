# walkingkangaroo.com

The Walking Kangaroo website: the games and apps Grant is making, how far along each one is, and
a devlog. A static Astro site, published to GitHub Pages at https://walkingkangaroo.com when a
pull request merges to `main`.

The repo is `walkingkangaroo/walkingkangaroo-web`, a pnpm workspace. The hub, walkingkangaroo.com,
is in `sites/hub/`. Run `pnpm install`, then `pnpm build`, `pnpm check` or `pnpm dev` from the
root; the build writes `sites/hub/dist/`.
